FLORA & BOTANICA — Авторские букеты 🌸

Элегантный и интерактивный лендинг для студии авторской флористики FLORA & BOTANICA. Сайт снабжен анимированным фоном Canvas, каталогом с 3D-переворотом карточек, системой избранного с хранением в состоянии приложения, каруселью отзывов и формой обратной связи.

🚀 Функциональные возможности

Интерактивный Canvas-фон: Реализована анимация падающих лепестков и мерцающих частиц, реагирующих на движения курсора и сенсорный ввод.

Каталог с 3D-эффектом: Карточки товаров переворачиваются при наведении, открывая состав букета, информацию о стойкости и кнопки действий.

Модальное окно «Избранное»:

Возможность добавления/удаления букетов в список избранного прямо с карточки.

Счетчик в шапке сайта, обновляющийся в реальном времени.

Просмотр избранных товаров в отдельном модальном окне с возможностью моментального перехода к заказу.

Быстрый заказ: Модальное окно оформления заказа с автоподстановкой названия выбранного букета.

Карусель отзывов: Интерактивная лента публикаций с отзывами покупателей и возможностью прокрутки.

Адаптивная верстка и мобильное меню: Удобный интерфейс для любых устройств с выпадающим бургер-меню для мобильных экранов.

Анимированный баннер: Декоративный блок с пульсирующими и вращающимися звездочками на CSS.

🛠 Технологический стек

HTML5: Семантическая верстка (<header>, <main>, <section>, <article>, <footer>).

CSS3:

Flexbox и CSS Grid для построения сеток.

CSS-переменные (:root) для управления цветовой палитрой.

3D-трансформации (perspective, rotateY, transform-style: preserve-3d).

CSS-анимации (@keyframes).

Медиазапросы (@media) для адаптивности.

JavaScript (Vanilla JS, ES6+):

HTML5 Canvas API для создания процедурной анимации лепестков и частиц.

DOM API для интерактивного взаимодействия (модальные окна, карусель, бургер-меню).

Управление состоянием избранных товаров в массиве favorites.

Шрифты: Google Fonts (Montserrat, Playfair Display).

💻 Запуск проекта

Клонируйте репозиторий или скачайте исходные файлы:

git clone https://github.com/Linakond00/flora-botanica.git


Убедитесь, что изображения букетов размещены в папке images/ в соответствии со путями, указанными в index.html.
